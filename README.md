# NEON VELOCITY — Cyberpunk Rescue

**Live website:** https://anuveytq-sys.github.io/Neon-City/

A landscape-first, third-person 3D parkour adventure built for the web.

## Current build
The main branch contains the playable Neon District plus progression, accessibility, campaign UI, final QA, photo mode, speedrun tooling, day/night controls, panel safety and visual polish.

## Run locally
```bash
npm install
npm run dev
```

## Controls
WASD / arrows to move · Space to jump · Shift to sprint · mouse/touch to look · P to pause.
